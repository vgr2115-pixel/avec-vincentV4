# Factures AVEC VINCENT

Le dossier contient un modèle de facture autonome et un registre vierge à copier dans un emplacement privé.

## Utilisation rapide

1. Copiez `modele-facture.html` hors du dépôt public, puis ouvrez cette copie dans un navigateur.
2. Renseignez le numéro de facture, le client, la prestation et le prix total affiché.
3. Laissez **Franchise en base** tant que votre régime de TVA n'a pas été modifié ou confirmé par votre service des impôts. Le modèle ajoute alors la mention `TVA non applicable, art. 293 B du CGI`.
4. Sélectionnez **TVA 20 %** uniquement si vous êtes effectivement redevable de la TVA ou si vous avez exercé une option. Le modèle calcule alors automatiquement le HT, la TVA et le TTC à partir du prix total saisi.
5. Imprimez la facture ou choisissez « Enregistrer au format PDF ». Conservez le PDF avec les justificatifs de paiement.
6. Tenez le registre `registre-factures.csv` dans une copie privée, avec une numérotation chronologique et continue.

Les coordonnées d'AVEC VINCENT sont déjà préremplies dans le modèle : vérifiez-les avant la première facture et complétez les éléments entre crochets dans `legal.html` avant publication. Ne renseignez jamais de données de clients dans le dépôt public GitHub.

Le modèle est conçu pour un cours individuel payé en espèces à la fin de la séance. Il reste à adapter en cas d'acompte, de prestation particulière, de client professionnel ou de changement de régime fiscal. Il ne remplace pas une validation de votre régime par le SIE ou un conseil comptable.
